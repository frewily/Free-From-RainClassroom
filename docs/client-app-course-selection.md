# 安卓课程班级选择：0.4.0

本切片在已有雨课堂登录上增加课程班级读取、勾选及本机恢复。界面和本机选择不会启用监听，也不会向云端写入课程、课表或凭据。

## 范围和用户流程

雨课堂页已登录时显示“选择课程班级”。进入后读取未归档的学生班级，可以搜索课程／班级／教师、分别勾选同名班级，点击“保存选择”。“查看归档班级”切换读取另一份列表，不会改变服务端归档状态，也不会清空本机选择。

选择按站点、账号和班级标识保存；再次打开时重新读取当前账号，并恢复该账号的选择。当前列表中没有出现的已选班级仍保留，用户可通过“清空选择”显式移除。页面始终说明“尚未配置时间／启用监听”。

## 只读接口与字段依据

客户端只有以下三个固定 HTTPS GET 资源，不接受任意目标 URL、请求方法或外部跳转：

| 资源 | 用途与读取字段 |
| --- | --- |
| `changjiang.yuketang.cn/v2/api/web/userinfo` | 使用 `data[0].user_id` 确定当前账号归属，与官方首页和归档查询一致 |
| `/v2/api/web/courses/list?identity=2` | 学生“我听的课”；班级用 `classroom_id`，课程名用 `course.name`，班名用 `name` |
| `/v2/api/web/classroom_archive?user_id=<当前账号>` | 只消费归档中的学生 `data.classrooms`；官方归档卡片使用 `id` 作为班级标识 |

归档与未归档的字段差异来自前一轮官方发布代码调查。可用时保留课程标识、原始学期标记、教师显示名与角色；未提供的学期保持未知，不从班名、历史开课时间或其他学校编号推算。当前不读取教学班详情、课次、正在上课接口或未来安排。

归档班级属于课程班级列表的一部分，不等于历史课堂记录；本切片也没有查询当前正在上课的课堂。完整已加入列表、正在上课、历史课次和未来逐次日期／起止时间继续作为四类不同数据验收。

列表超过 20 条时不截取前 20 条。识别到分页／下一页提示或总数大于本次条数时，明确显示未完整加载并禁止覆盖选择，不猜测下一页参数，也不跟随响应提供的 URL。条目缺少关键字段或班级标识重复时整体失败，不静默丢弃异常行。内部 `complete` 只表示本次条目有效且没有已识别的截断提示，不是全站、全部角色或所有历史课程的完整性证明。

## 本机保存与失败处理

- 继续使用现有本机会话，不提供粘贴或导出凭据入口。
- 选择使用独立安全存储，按站点及当前账号摘要分键，仅保存版本、归属与选中班级 ID，不持久化原始响应或整份个人课程列表。
- 加载、保存成功和失败都核对本机会话是否变化；旧账号的晚到结果不能覆盖新账号，也不能把旧选择写入另一个账号的记录。
- 网络异常保留上一份同账号的内存列表及选择；明确失效时隐藏旧账号数据、提示返回登录页。读取失败不显示“没有课程”。重开后如不能确认账号，不展示上次账号的课程数据。
- 保存失败保留待保存选择，不显示保存成功。存储写入按序执行，记录尺寸不超过已有安全存储读取限制。
- HTTP 不跟随重定向；响应上限为 1 MiB，连接与整次请求都有超时。错误仅保留安全分类、固定读取阶段和 HTTP 状态，不输出 Cookie、原始异常或原始个人响应。

## 与现有执行端的边界

本切片没有读取或调用签到、加入、答题和提交接口，没有修改 Python、Worker、Cron 或正式云端配置。既有 Python 按名称筛选及筛选前仍可能签到的行为，不因本机勾选而改变。班级选择同步到执行端、私有时间来源和正式启用属于后续独立切片。

当前限定长江站。其他雨课堂站点、教师课程、未来逐次时间、Mac Flutter 及长期调度尚未由本切片验收。
