## 目标流程

1. 软件中点击“绑定 Cloudflare”，打开官方授权页。
2. 主人在官方页核对应用及权限，选择自己的原账号并完成授权。
3. 授权结果由手机本机接收；返回软件后核对账号，再独立加密保存本机连接。
4. 重开时检查连接与账号；过期时提示重新授权，断网时保留记录。

Cloudflare 连接页只读身份与账号信息；同包的“部署验证”页在主人核对具体清单并确认后创建一个合成测试 Worker 和原空仓库的一份工作流，触发一次空任务并查看结果。KV、D1、Secrets、DNS 和 Cron 不在本次测试部署内。Cloudflare 本机退出不影响雨课堂、GitHub 连接或云端运行。

## 实现时重点处理

- 本机端口占用时先停止，不开始授权；只监听 `127.0.0.1`，设置等待上限并在取消／完成后关闭。
- 核对 state、回调路径、参数和实际 scope；异常或重复回调不能重复交换授权码或覆盖已有连接。
- 回调页只提示“已收到结果，请返回应用查看”，不提前声称账号验证成功，不展示授权码或令牌。
- 复用安全存储插件，使用独立 Cloudflare 命名空间；实际保存期限来自官方返回，不猜测有效期，不默认已具备 Cloudflare 自动续期。
- 保留前两段的取消、旧请求隔离、串行保存与删除规则；不影响已验收的两个连接。
- PKCE 的 SHA-256 已复用现有锁文件与缓存中的 Dart `crypto 3.0.8`，以相同版本离线升为直接依赖；已核对锁文件仅改变归类，无新包下载或版本变化。
