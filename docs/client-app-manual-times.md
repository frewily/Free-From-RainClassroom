# 安卓本机手工上课时间：0.5.0

本阶段在已保存的课程班级选择上增加单次时间录入、有限范围内的每周批量生成、单次修改／删除、本机保存和重开恢复。用户已确认“单次＋每周批量”范围；当前没有课表上传、正式调度或课堂动作。

## 用户流程与时间规则

1. 在“选择课程班级”中勾选班级并保存，点击班级右侧时钟进入“手工上课时间”。未保存的选课草稿不能进入时间编辑。
2. 点击“添加课次”，选择日期、开始／结束时间；可打开“每周重复”，选择截止日期。
3. 点击“预览实际课次”，核对展开的具体日期和时段，再“加入待保存安排”。更改输入会使先前预览失效。
4. 核对页面中的全部实际课次，点击“保存本机时间”。显示“本机时间已保存”后才算保存完成；有未保存更改时返回会询问是否放弃。
5. “修改这次”或“删除这次”只作用于所点的一个具体课次，之后再次保存。每周批量生成后不保留无限重复规则，不自动跟随节假日、调课或学期变化。

时间固定为**北京时间 UTC+8（`Asia/Shanghai`）**，不随手机系统时区转换。日期校验与按周生成使用 UTC 日历运算，持久化的是不带设备时区转换的日期和当天分钟数。默认日期按北京时间的“今天”计算。

- 日期限 2000–2100 年；开始／结束以分钟录入，仅支持同日、结束晚于开始，最晚 23:59；本轮不支持跨午夜或 `24:00`。
- 每周以首次日期的星期几为准，截止日包含在范围内，首次到截止日最多 366 个日历日；最多生成 53 次。
- 每班最多 200 次；同班同日的重复或重叠时段整体拒绝，相邻时段允许。批量中任意冲突均不加入，保留原草稿。不同班级间的冲突暂需用户自行核对。
- 取消选课不删除该班级的本机时间，重新选择并保存后可继续查看。未显示在课程列表中的已选班级，本阶段不凭空生成编辑入口。

## 标识、存储与会话边界

每份时间记录按站点、雨课堂账号和**班级 ID** 隔离，使用已有安全存储，键名为归属摘要。只保存版本、归属、班级 ID、固定时区、`manual` 来源及具体日期／分钟，不保存课程名称、教师、原始课程响应或会话。

班级 ID 来自已验证的课程列表，未归档为 `classroom_id`、归档为 `id`。这些手工安排没有服务端 `lessonId` 或教务原始课次标识；不能拿本机日期／分钟组合冒充服务端课次，也不能声称已完成监听端 ID 匹配。

时间页复用父课程页已确认的账号归属，不取得会话副本，也不额外发送网络请求。加载和保存前后重新核对本机会话及该班级是否仍在安全保存的选课中；会话或选择变化时隐藏旧数据、要求返回课程页重开。存储失败保留可重试草稿；坏版本、错误归属／时区、异常日期或重叠记录不能被空列表静默覆盖。

记录沿用安全存储写入后的回读检查，操作按序执行，大小限 65,536 字符。进程在写入途中终止、设备损坏或另一客户端并发写入的原子性不在本阶段保证范围内；不会将一次显示保存成功外推为备份或跨设备同步能力。当前绑定的是父课程页已验证的会话，时间页不额外检测服务端会话到期。
